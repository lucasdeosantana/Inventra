# Inventra Frontend 2

Frontend administrativo do Inventra, construído para gerenciar produtos, posições e consultar o histórico de movimentações do banco de dados.

## Visão geral

- CRUD de produtos com criação, edição, busca e remoção lógica.
- CRUD de posições com criação, edição, busca e remoção baseada nas regras do backend.
- Visualização da árvore hierárquica de posições.
- Consulta do histórico de movimentações armazenadas no banco.

## Requisitos

- Node.js 18+
- Backend Inventra em execução em `http://localhost:3000`

## Execução

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
